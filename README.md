# Sugarcane Land Marketplace

Express + EJS web app for posting sugarcane land listings with sale and lease options.

## Run locally

1. Open the project folder in a terminal.
2. Install dependencies:

```bash
npm install
```

3. Start the server:

```bash
npm start
```

4. Open `http://localhost:3000` in your browser.

## Project structure

- `app.js` - main Express server
- `views/` - EJS templates for pages and partials
- `public/` - static assets such as `styles.css`
- `db/` - SQLite database storage created automatically
